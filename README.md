# ackermann-robotic-arm-car
# 基于阿克曼转向底盘的多模式智能移动机械臂机器人

## 1. 项目简介

本项目设计并实现了一款集自主移动、环境感知、智能避障、自动循迹及机械臂操控于一体的多功能移动机器人。

机器人采用阿克曼转向底盘，搭载四自由度舵机机械臂，通过嵌入式控制系统实现移动平台与机械臂的控制。

## 2. 主要功能

- **红外遥控：** 实现小车前进、后退及方向控制。
- **超声波避障：** 检测前方障碍物，根据距离信息自动调整行驶方向。
- **自动循迹：** 利用红外循迹模块识别地面路径，实现自动跟踪。
- **机械臂控制：** 通过遥控手柄控制四自由度舵机机械臂运动。
- **阿克曼转向：** 通过转向机构实现移动底盘的方向控制。

## 3. 核心技术

- 阿克曼转向机构与运动控制
- 嵌入式系统控制
- 红外传感器检测
- 超声波测距与避障
- PWM舵机控制
- 多模块机电系统集成

## 4. 硬件组成
